How ranking works
Your question is reduced to keywords (filler words removed), then searched once per source, all in parallel. Every result from every source is scored the same way, strongest signal first: query words in the title, query words together as a phrase in the title ("Change a Tire" beats "Change a Motorcycle Tire"), a source match for the kind of question (e.g. "how to" favors WikiHow), then query words in the snippet. Ties go to the more on-topic title, then the source's own ranking, then source name. Nothing depends on timing, so the same question always gives the same order.
